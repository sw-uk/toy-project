# 데이터 공개와 표현의 선

## Decisions

- 누구나 접근할 수 있는 공개 거래 기록과 익명 지갑 주소는 그대로 공개한다. 한 건의 베팅도 숨기지 않는다.
- 지갑을 실명, 소속, 기관과 연결하지 않는다.
- 특정인이나 기관을 내부자 거래, 불법 행위로 단정하지 않는다. 거래 패턴은 시각, 금액, 가격, 수익 같은 관찰된 사실로만 표현하고, 화면은 그것이 결론이 아님을 알린다.
- 데이터 제공처의 이용 조건과 지역 제한은 우회하지 않는다.
- 확률에서 계산한 시점 안내는 수학적 계산 결과이며 투자 권유가 아님을 모든 화면에서 알리고, 모든 투자 판단의 책임이 이용자에게 있음을 고지한다.

## Boundaries

- 눈에 띄는 베팅 공개는 개별 뉴스나 이벤트 단위에 한정한다. 여러 이벤트에 걸친 전체 기간 상위 수익자 순위는 만들지 않는다.
- 금융상품의 판매, 추천, 가입 연결은 하지 않는다.

## Why

일반인이 "누가 이벤트 직전에 얼마를 걸어 벌었나"를 직접 확인하게 하려면 공개 기록을 줄이지 않아야 한다. 반면 지갑 주소는 실명이 아니므로, 단정 표현이 틀리면 엉뚱한 사람이나 기관에 대한 허위 주장이 된다. 사실을 그대로 보여 주되 해석은 방문자에게 남기는 선이 공개 범위를 줄이지 않으면서 사이트가 법적·사실적으로 설 수 있는 지점이다. 이 선은 사용자가 공개 범위의 판단을 위임하며 정했고, 사용자가 보고 수정하지 않았다.

## Reconsider when

- 법률 검토나 데이터 제공처의 이용 조건이 지갑 단위 공개를 금지하거나 제한하는 것으로 확인될 때
- 실제 이용에서 "관찰된 패턴"이라는 표현이 오해를 막지 못한다는 반복 가능한 근거가 생길 때

## Still-rejected alternatives

- 지갑이나 이벤트를 내부자 거래 의심 대상으로 직접 표시하는 방식 — 틀렸을 때 허위 사실을 퍼뜨리는 책임을 사이트가 진다.
- 지갑 정보를 아예 비공개로 두는 방식 — 사용자가 알고 싶은 핵심 정보(누가, 얼마, 언제)를 잃는다.
